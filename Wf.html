Project-Level Workflow

Deferred

Portfolio Backlog

Default status when a request form is submitted. The project auto-creates in Wrike with this status.

Reporting

Move to this phase when the campaign is launched. During this phase the PM monitors performance, makes minor optimizations, and completes wrap-up tasks such as reporting, documenting lessons learned, and archiving.

On Hold

Use only if the project is intentionally paused for a significant period. Provide context in the project description or comments. Reactivate by moving back to the appropriate active phase once work resumes.

Active

Planning

PM is ready to begin reviews/refine the creative brief, confirms assets and channels, builds the Wrike project plan, assigns and aligns resources, and confirms dates and metrics.

Execution

Select when assets are actively being produced. Cross-team coordination is underway. This status generally begins when work tasks are assigned to doers and continues until campaign deliverables are ready for launch.

Completed

Complete

Use when the campaign is formally closed and no more active work will occur. This status is necessary for accurate reporting and to indicate that all tasks are completed.

Cancelled

Cancelled

Use when the project will not be completed. All associated tasks should be cancelled or updated accordingly. Document the rationale in comments.
